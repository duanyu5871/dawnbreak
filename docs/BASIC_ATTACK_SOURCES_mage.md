## 2. 战斗法师（배틀메이지）普攻

出处：<https://namu.wiki/w/배틀메이지(던전앤파이터)/스킬>

- 圆舞棍（원무곤）一栏：`평타 3타를 캔슬하고 사용할 경우 평타 범위를 잡는다.` → **战斗法师的普攻至少有 3 段**，和游戏里 `BM_ACTS` 的 atk1-3（刺 → 上挑 → 横扫）一致，**不改**。
- 同页只记录了段数，没有写每一段的动作、判定数。**每段的动作和 hit 数没有找到出处**，保持原样。
- 该技能页的目录里没有 천격 / 용아 的条目（只有 원무곤、더블 스윙、쇄패、뇌연격 等；창页面的 라바 파나카 文字里仍提到 용아），所以韩服技能页查不到它们的霸体描述。
- 武器精通：<https://namu.wiki/w/던전앤파이터/아이템/창> 的 라바 파나카 一栏写着 `찌르기 스킬: 용아, 원무곤, 뇌연격, 황룡천공, 황룡난무 / 체술 스킬: 쇄패, 강습유성타, ...` → 用矛时"찌르기（突刺）技能"和"体术技能"会被加强，说的是技能，不是普攻。游戏里 `rngMul = 1.2` 只作用于技能，和这个方向一致（具体 +20% 没有出处，未动）。
- 速度：<https://namu.wiki/w/배틀메이지(던전앤파이터)> 写着 `속도 보정치 총합은 공격속도 79.5%, 이동 속도 90%`、`천격, 낙화장, 쇄패로 대표되는 시원시원한 동작` → 战斗法师本来就很快（游戏里 `bm_will`、炫纹等已实现）。

## 3. 天击（mg_sky）/ 龙牙（mg_fang）是否霸体

- **没找到页面级出处。** namu 没有这两个技能的单独页面（`/w/천격` 404），biligame 的 `wiki.biligame.com/dnf/…` 抓下来是 BWIKI 导航壳，没有 DNF 内容；Fandom DFO wiki 直接 403（API 能连但没有 Battle Mage 条目）；dnf.qq.com 没有抓到可用的技能页（未找到确切 URL）。
- 只有 `search_web` 的摘要（17173 / colg / qq.com 的转述，**未验证**）：天击"不带霸体，施放时按 ↑↓ 会先侧滑再攻击"，龙牙"不带霸体"。这条和游戏里 `mg_sky` 已经是 `noSA: true`、侧滑实现一致。
- 处理：`mg_sky` 保持 `noSA`（与已有的"官方：天击滑动、非霸体"注释和摘要一致）；`mg_fang` 没有可靠出处 → **不改**。

## 5. 元素师 / 召唤师 / 小魔女 的普攻

- 元素师：<https://namu.wiki/w/엘레멘탈마스터(던전 앤 파이터)> 写着 `빗나가면 넘어지는 대쉬 공격은 평타 패턴에서 실수할 경우 치명적인 문제가 될 수 있어서 불만의 목소리가 나오고 있다. ... 여성 마법사의 평타 자체가 판정도 안 좋기 때문에` → **元素师用的就是女魔法师通用普攻**（冲刺攻击打空会摔倒、判定不好），游戏里 `MAGE_ACTS` + `MAGE_TRIP` 已经是这个行为，**不需要给元素师单独做普攻**。
- 召唤师（<https://namu.wiki/w/소환사(던전 앤 파이터)>）：页面里按关键字（평타 / 기본공격）检索没有发现普攻专属描述；魔杖页写 `빠른 공격속도와 캐스트속도는 소환수를 뽑아놓고 딜을 하는 소환사의 딜링 방식에 거의 이점을 가져다주지 못하기 때문이다` → 只是武器选择，不是动作差异。**保持沿用通用普攻。**
