## 3. 各转职普攻

| 项 | 原文 | 结论 |
|---|---|---|
| 漫游枪手：普攻里有没有体术 | namu-레인저：`전직 이전처럼 권총을 사용하면서 체술을 쓰는 방식`（체술 = 技能：태권 기술 / 윈드밀 / 건블레이드）；`헤드샷, 트리플 탭조차도 공격범위가 평타와 다를 게 없이 극단적으로 좁아` | 体术全是**技能**，普攻仍是射击。**撤销**首版里"左轮收枪段改回旋踢 / 滑铲带枪刃斩光"（无出处） |
| 漫游：低射 | namu-레인저 여자：`빠른 공격속도를 이용해 하단 평타를 계속 끊어치는 일명 짤짤이` | ↓ 低射已有（打倒地），不改 |
| 枪炮师 | namu-런처：`보통 여런처의 기본기는 레이저 라이플/화염 강타 중 1택`、`평타를 쓸 일이 거의 없으므로 핸드캐넌의 짧은 사거리도 문제 되지 않는다`；`런처는 기본기인 슬라이딩 말고는 이동기가 없는 편` | 没有枪炮师专属普攻 / 跑攻：**保留"无武器默认手炮手感"**（手炮是其主武器，런처 중화기 마스터리绑定手炮）。**撤销**首版的"换枪后硬直×1.25 / 击退×1.4 / 收枪×1.12"和普攻额外震屏（无出处） |
| 机械师 | namu-메카닉 页面无普攻描述 | **撤销**首版自动手枪"电光青色弹"（纯杜撰）；普攻 = 自动手枪通用 |
| 弹药专家 | namu-스핏파이어：`관통탄과 폭발탄 중 하나를 선택해 평타를 강화할 수 있다`；装备项 `폭발탄 (공격력 15%, 폭발 크기 30%)` | 爆炸弹放大保留（出处：爆炸尺寸）；橙红弹色属美术取舍，无出处，仅保留 |
| 协战师 | namu-패러메딕：只有"强袭套装（강습슈트）有专属动作"，没有普攻细节；`무기강화 - 기본 공격 버프` | 战斗服普攻不动；首版 `airLift 90→120` 只是与基础跳攻保持一致，保留 |

## 4. 跑攻（滑铲）/ 跳攻

- namu-거너：`대시 공격인 슬라이딩은 X축 이동에 특화되어 있어 따로 이동 스킬을 배우지 않아도 이동이 수월한 편이다`。→ **所有神枪手跑攻 = 滑铲**，没有枪炮师的肩撞 / 炮托跑攻出处，**保持不变**；也撤掉了漫游滑铲的枪刃光。
- namu-레인저 여자：`최근 사냥 패치가 넘어오면서 대쉬중 패건평타 사용이 불가능해지면서 … 관성 평타 등을 이용해서 … 대쉬후 평타를 여전히 사용`（패건 = 패스티스트 건，已有等价技能 `g_quickdraw`，本任务不动）。
- 跳攻 = 公中射击（斜下射、反冲），见第 2 表。
